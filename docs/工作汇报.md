# 工作汇报

**项目名称**：ID-009 AI 模型评测平台（一站式大模型评测、评分图谱与性价比分析平台）
**所属组织**：SME
**汇报人**：查锐
**汇报日期**：2026 年 9 月 18 日

---

## 一、工作概述

本报告期内，本人围绕 ID-009 AI 模型评测平台开展了全栈开发与交付工作。该平台面向大语言模型（LLM）评测场景，覆盖模型注册、数据集管理、评测任务调度、六能力域评分、成本分析及评分—成本 Pareto 图谱可视化等完整业务闭环。目前平台已完成核心功能开发、容器化部署方案落地及演示数据配置，整体达到可交付、可演示状态。

## 二、本期完成的主要工作

### （一）后端服务建设

1. 基于 Litestar + Granian + Strawberry GraphQL 技术栈，完成后端服务整体搭建，对外提供统一 GraphQL 接口；
2. 实现模型注册中心功能，支持自研、开源、商用 API 三类接入方式的统一登记与元数据管理；
3. 实现评测任务调度模块，构建完整的任务状态机（Draft → Pending → Running → Paused → Done / Failed），并通过守护线程实现进度每秒推进与持久化落库，支持服务重启后的断点续跑（resumeTask）；
4. 实现六能力域评分体系（客观知识与推理、语言与生成、对齐与安全、长上下文、多模态、业务专项），按预定义权重（推理 30%、语言 20%、对齐 15%、长上下文 15%、多模态 10%、业务 10%）加权聚合综合评分；
5. 在服务端内置 Pareto 前沿计算引擎，直接返回按成本升序、评分刷新包络的前沿点列与性价比排名，降低前端渲染复杂度；
6. 完成用户认证体系建设，覆盖注册、登录、令牌认证、密码重置全流程。

### （二）前端界面建设

1. 基于 Next.js 16 + HeroUI + Tailwind CSS 4 + Framer Motion 完成前端开发，与后端 GraphQL 接口深度集成；
2. 实现评分—成本交互式气泡图可视化，X 轴为每任务推理成本（USD），Y 轴为综合评分，支持多维度筛选与 Pareto 前沿标注；
3. 前端视觉遵循学术刊物图表规范（Nature / Science 风格），采用黑白学术风格 UI 与高对比低饱和厂商调色板，突出专业性与可读性。

### （三）部署与数据配置

1. 完成四容器 Pod（HAProxy + Next.js + Litestar + PostgreSQL 18）一键部署方案，`./up.sh` 幂等启动，30 秒内可完成全栈部署；
2. 编写数据库初始化与种子数据脚本，首次建库自动注入 34 个主流模型（覆盖 10 家厂商）、6 个评测数据集（六能力域各一）及 34 个已完成评测任务与结果，确保评分图谱开箱即有数据；
3. 本期对演示种子数据进行了精简优化，将样例数据由 44 组核减至 34 组，在保证评分×成本分布覆盖度的前提下控制数据规模，提升演示加载效率与可读性。

## 三、阶段性成果

1. 平台核心功能已全部贯通，形成"评测执行—结果聚合—可视化分析"的完整业务闭环，可支撑团队快速完成模型选型与性价比决策；
2. 任务状态机与断点续跑机制经过验证，工程可靠性达到预期；
3. 部署方案稳定，演示环境可一键拉起，开箱即用；
4. 累计形成 15 次以上版本提交，代码迭代有序、可追溯。

## 四、存在的问题与风险

1. 各大模型平台评测引擎后需对评分口径进行校准；
2. 商用 API 的配额与成本控制有待在实测中进一步验证；
3. 前端大数据量场景下的图谱渲染性能尚需进一步压测与优化。

## 五、下一步工作计划

1. 完善增量评测任务与存量种子数据的风格一致性校验机制；
2. 开展前端图谱渲染性能优化及多端适配测试；
3. 补充自动化测试用例，提升代码质量与回归保障能力。

## 六、总结

报告期内各项工作按计划推进，ID-009 AI 模型评测平台已达到可交付、可演示的阶段性目标。后续将聚焦真实评测能力接入与性能优化，持续完善平台功能，确保项目高质量落地。
